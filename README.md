# UPI Transaction Analytics Dashboard

Power BI dashboard analysing 250K UPI transactions from the upi_transactions_2024 dataset (January to December 2024), covering transaction performance and fraud risk.

## Key numbers
- Total transactions: 250K
- Total transaction amount: 328M
- Average transaction amount: 1.31K
- Successful transactions: 237.624K (95.05% success rate)
- Fraud transactions: 480 (fraud amount 720K, average 1.50K)

## Key findings
- P2P is the most frequently used transaction type
- Shopping has the highest transaction amount among merchant categories
- Maharashtra records the highest number of transactions
- Android devices and 4G networks have the highest fraud cases
- Fraud is highest among the 26-35 age group
- Fraud activity peaks during the evening hours (around 8 PM)

## Dashboard pages
1. Transaction Performance Overview
2. UPI Fraud and Risk Analysis
